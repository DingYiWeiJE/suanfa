# 按需加载
```
                 Vue 项目
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
    unplugin-auto-import   unplugin-vue-components
          │                   │
          ↓                   ↓
     自动导入 API          自动导入组件
          │                   │
          ↓                   ↓
   ref / computed          UserCard
   reactive / watch        ElButton
   useRoute                ElTable
   useRouter               ElDialog
   ```
